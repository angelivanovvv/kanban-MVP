# Forma Kanban

A simple Next.js Kanban board with five renameable columns, sample cards, and drag and drop. No persistence or accounts.

```sh
cd frontend
npm install
npm run dev -- --port 3001
```

Open http://localhost:3001. See [frontend/README.md](frontend/README.md) for test commands and [PLAN.md](PLAN.md) for verified completion criteria.
